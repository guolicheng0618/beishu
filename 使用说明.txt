考研背书手账 · 使用说明
========================================

一个网页小工具，帮你做这些事：
  1) 记录今天背了什么，自动按艾宾浩斯遗忘曲线安排复习
  2) 每天告诉你该复习哪几条，复习完自评"记得/模糊/忘记"
  3) 随机抽背，先看问题再翻答案
  4) 记自己的待办备忘（和自动生成的复习计划分开）
  5) 累的时候，有个陪你聊两句的地方

单用户、纯前端、不用注册、不上传任何数据。
所有内容都存在你自己的浏览器里。


一、怎么打开（电脑上）
----------------------------------------
1. 把压缩包解压到一个文件夹（比如桌面）。
2. 双击 index.html，用 Chrome 或 Edge 打开，就可以开始用了。
   * 建议固定到书签栏，以后一点就开。
   * 不要只把 index.html 单独拖出来，放在文件夹里更稳妥。


二、在手机 / 平板上用（三种方法，选一种）
----------------------------------------
先记住一件事：这三种方式的数据是【各自独立】的（因为访问地址不同）。
所以想在哪台设备上都看到同样的内容，要用「设置/备份 → 导出 JSON 备份」，
把文件发到另一台设备再「导入 JSON 恢复」。微信"文件传输助手"最方便。


【方法一】同一个 Wi-Fi 下访问你的电脑（已经帮你设好了，不用注册任何东西）
  * 电脑开机后会自动启动这个小服务，你不用管它。
  * 地址随时可以看「手机平板访问」文件夹里的【手机访问地址.txt】，
    打开后大概长这样：  http://192.168.43.138:8080/
  * 让手机 / 平板连上和电脑【同一个 Wi-Fi】，然后用浏览器打开这个地址。
  * 打开后建议在浏览器菜单里选「添加到主屏幕」，以后一点就开。
  * 想手动启动 / 停止：双击「启动手机访问.cmd」/「关闭手机访问服务.cmd」。
  * 手机打不开的话，双击「如果手机连不上-点我修复.cmd」（它会请求一次管理员权限）。

  适合：在家、在宿舍，电脑开着的时候。
  注意：① 手机和电脑必须在同一个 Wi-Fi；
        ② 电脑睡眠 / 关机后手机上就打不开了；
        ③ 电脑换了网络，地址里的数字（IP）可能会变，以【手机访问地址.txt】为准；
        ④ 这个服务只把「手机平板访问」文件夹里的网页提供出去，
           你的背诵内容存在浏览器本地，不会通过网络传出去。


【方法二】发布成一个固定网址（推荐，随时随地能用）
  有了固定网址，手机、平板、电脑打开的都是同一个地址，
  不用开电脑，也不用待在同一个 Wi-Fi。免费做法（GitHub Pages）：

  1) 打开 https://github.com ，注册 / 登录（免费）。
  2) 右上角 "+" → New repository：
        Repository name 随便填，比如 beishu
        勾选 Public（免费账号的 Pages 需要公开仓库）
        Create repository
  3) 在新仓库页面点 "uploading an existing file"，
     把 index.html 拖进去，下面点 Commit changes。
  4) 点仓库上方的 Settings → 左侧 Pages →
        Source 选 "Deploy from a branch"，
        Branch 选 main，文件夹选 / (root)，点 Save。
  5) 等 1~2 分钟，刷新这个页面，顶部会出现你的网址，形如：
        https://你的用户名.github.io/beishu/
     这个就是可以随时打开的网址了。

  手机 / 平板上把这个网址打开，然后在浏览器菜单里选「添加到主屏幕」，
  桌面就会出现一个图标，点开就是全屏的记账本，像 APP 一样。

  注意：① 这是公开网址，任何知道地址的人都能打开网页，
           但【数据只存在各自设备的浏览器里，谁也看不到你的数据】；
        ② 国内访问 github.io 有时会慢一点，加载慢的话多等一会儿；
        ③ 以后改了这个网页，重新上传一次 index.html 覆盖即可。


【方法三】直接把文件拷到设备上打开（不需要电脑和网络）
  把 index.html 传到手机 / 平板上（微信文件传输助手、数据线都行），
  然后用浏览器打开这个文件。
  * 安卓：一般可以用「文件管理」找到它 → 打开方式选 Chrome，可以用。
  * iPhone / iPad：系统不太支持直接用 Safari 打开本地网页文件，
    不推荐这种方式，建议用方法一或方法二。
  * 用这种方式时，数据存在那台设备的浏览器里。
    注意别清理浏览器数据，否则会丢。


该选哪个？
  * 只在宿舍/家里用，电脑经常开着   → 方法一
  * 想天天用、去图书馆也用、随时打开 → 方法二（推荐）
  * 只是临时看一眼、不方便联网     → 方法三


三、数据存在哪里（请一定看这段）
----------------------------------------
* 数据存在【你这台设备的这个浏览器】里（技术上说叫 localStorage）。
  关掉网页、重启设备都还在，不需要保存文件。
* 但是：换浏览器、换设备、清理浏览器数据/"清除缓存"、无痕模式，
  数据就没了。所以请养成习惯：
      设置/备份 → 导出 JSON 备份
  存一份到自己网盘或发给自己。以后换设备，在新设备上"导入 JSON 恢复"即可。
* 导出的备份文件包含：背诵条目、复习历史、备忘录、聊天记录和设置。
  为了安全，备份里【不包含 API Key】（AI 陪伴的 Key 需要重新填一次）。
* 网页本身不上传任何数据；只有你自己开了"在线 AI 模式"时，
  聊天内容才会发给你自己填的那个 API 地址。


四、四个复习相关的功能
----------------------------------------
【录入背诵】
  填科目、章节、标题、问题、答案、重要程度、学习日期，保存后自动排好复习计划。
  默认间隔是学习后第 1、2、4、7、15、30 天（可以在"设置/备份"里改）。
  批量录入：展开"快速批量录入"，一行一条，格式是
      科目 | 问题 | 答案
  例：教育学 | 教育的本质是什么？ | 教育是有目的地培养人的社会活动

【今日复习】
  打开网页就算好了今天该复习哪些，顶部一直显示"今日待复习 N 条"。
  每条点开"看答案"，然后诚实地选一个：
      记得 → 进入下一个阶段，下次间隔更长
      模糊 → 阶段不变，明天再来一次
      忘记 → 重置到第一阶段，明天重来
  所有阶段走完就标为"已掌握"，60 天后再巩固一次（天数可改）。
  没有到期的内容时会提示"今天没有到期复习，可以自由安排"。
  逾期不会给你红色警告，只会温和标个"昨天/逾期 N 天"。

【抽背】
  可以从"今日待复习"里抽，也可以从"全部条目"里抽，还能指定科目。
  先只显示问题，想好了再点"显示答案"，然后自评。一轮结束会给出
  记得/模糊/忘记的数量统计。

【全部条目】
  搜索、按科目筛选，看每条复习过几次、历史自评记录，也能编辑和删除。


五、备忘录（自己记的待办，和复习计划分开）
----------------------------------------
* 只写一行内容就能存；展开"更多选项"可以加：备注、日期（也可以选"无日期"）、
  时间、类型（待办/学习计划/生活杂事/随手记）、优先级、标签、重复。
* 重复支持四种：不重复 / 每天 / 每周 / 每月。
  完成后会自动生成下一条（每天→明天，每周→7天后，每月→下个月同一天，
  比如 1月31日 → 2月28日），原来那条保留成完成记录。
* 首页顶部有"今日备忘"，会显示"今天有 N 件小事记得处理"，逾期单独提醒。
* 想收系统通知：点"开启到期提醒"并允许浏览器的通知权限即可。
  注意：只在网页打开时检查一次，关掉网页不会后台推送（故意做简单的，
  不装后台服务、不联网推送）。拒绝通知也完全不影响其他功能。


六、AI 陪伴怎么用
----------------------------------------
默认是【离线模式】：不联网，内置 70 多条温暖话术，按你说话的情绪匹配，
够平时说说话了。快捷按钮：夸夸我 / 安慰我一下 / 今天学得好累 / 我有点焦虑 /
帮我复盘今天 / 给我一句鼓励。

想用真正的 AI 对话：
  设置/备份 → AI 陪伴设置 → 回复模式改成"在线 AI 模式"，然后填：
      API 地址：https://api.deepseek.com/v1      模型：deepseek-chat
      API 地址：https://api.openai.com/v1         模型：gpt-4o-mini
  需要有你自己申请的 API Key（按用量计费，很便宜）。
  没填对 / 网络不通 / 超时，会自动退回离线话术并温和提示，不会卡住。

  ！提醒：单文件网页没有后端，Key 是明文存在本机浏览器里的。
    建议用权限最小、额度最小的 Key，别在公用设备上填。
    导出的备份文件里不会包含 API Key。

  聊天记录最多保留最近 200 条，超出自动删最旧的；"清空聊天"会二次确认。


七、快速上手建议
----------------------------------------
想先看看长什么样：设置/备份 → 导入 JSON 恢复 → 选【示例数据.json】，
就会有一批示范内容（几条背诵 + 几条备忘 + 一段聊天）。
看完点"清空全部数据"即可从零开始。


八、其他细节
----------------------------------------
* 顶部显示当前时间、日期、今日待复习数量，还有北京天气
  （来自 Open-Meteo 免费接口，无需密钥；拿不到时显示"暂时获取失败"，
   不影响其他任何功能）。
* 每天有一句"每日一句"和一件"拾取生活热爱的小事"，都按日期固定，
  第二天自动换新。
* 手机 / 平板上已做适配：输入框不会被自动放大、点击区域放大到手指好按、
  聊天区跟随屏幕高度、底部导航避开 iPhone 的底部横条。
* 数据全在一个 key 里：beishu_app_v1。


九、出问题了怎么办
----------------------------------------
* 打不开 / 白屏：换 Chrome 或 Edge 试试（很老的 IE 不行）。
* 手机上打不开方法一的地址：
    ① 确认手机和电脑连的是同一个 Wi-Fi（不是手机流量）；
    ② 确认那个黑窗口还开着；
    ③ 电脑上弹出的防火墙提示要点"允许访问"。
* 数据不见了：是不是清了浏览器数据、换了浏览器或换了访问方式？
  如果之前导出过备份，用"导入 JSON 恢复"能找回来。
* 想从零开始：设置/备份 → 清空全部数据（会二次确认，建议先导出备份）。

祝复习顺利，慢慢来，比较快。
