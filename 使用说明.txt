考研背书手账 · 使用说明
========================================

一个网页小工具，帮你做这些事：
  1) 第一轮：按章节记录今天背了什么，自动按艾宾浩斯遗忘曲线安排复习
  2) 第二轮：按模块（简答/名词解释/易混淆知识点/重难点/创新题）录入，随机抽题检验
  3) 每天告诉你该复习哪几条，复习完自评"记得/模糊/忘记"
  4) 随机抽背，先看问题再翻答案
  5) 记自己的待办备忘（和系统自动生成的复习计划分开）
  6) 累的时候，有个陪你聊两句的地方
  7) 顶部一直显示距离 12 月 19 日还有多少天

单用户、纯前端、不用注册、不上传任何数据。
所有内容都存在你自己的浏览器里。


一、怎么打开
----------------------------------------
方式 A（推荐，手机／平板／电脑都能用，电脑不用开着）：
     在浏览器打开你的固定网址，然后"添加到主屏幕"，以后一点就开。

方式 B（不开电脑也能用）：
     把 index.html 传到设备上，用浏览器打开。安卓方便，iPhone/iPad 不推荐。

方式 C（同一个 Wi-Fi 下访问电脑）：
     双击「启动手机访问.cmd」，用手机打开显示的地址。
     适合在家／宿舍，电脑开着的时候。


二、在手机 / 平板上用
----------------------------------------
最省事：扫二维码（二维码图片在同一个文件夹里）。
或者把网址发到微信"文件传输助手"，在手机上点一下打开。
打开后点浏览器菜单 →「添加到主屏幕」，以后就像 APP 一样。
（iPad：底部分享 ↑ → 添加到主屏幕；安卓：⋮ → 添加到主屏幕）

三种方式的数据是【各自独立】的（访问地址不同 = 存储不同）。
要让两边内容一致：在一边「设置/备份 → 导出 JSON 备份」，
把文件发到另一边，再「导入 JSON 恢复」。微信"文件传输助手"最方便。


三、数据存在哪里（请一定看这段）
----------------------------------------
* 数据存在【你这台设备的这个浏览器】里（技术上说叫 localStorage）。
  关掉网页、重启设备都还在，不需要保存文件。
* 但是：换浏览器、换设备、清理浏览器数据/"清除缓存"、无痕模式，
  数据就没了。所以请养成习惯：设置/备份 → 导出 JSON 备份。
* 导出的备份包含：第一轮条目 + 复习历史 + 第二轮强化题库 + 备忘录 +
  聊天记录 + 设置。为了安全，备份里【不包含 AI 的 API Key】。
* 网页本身不上传任何数据；只有你自己开了"在线 AI 模式"时，
  聊天内容才会发给你自己填的那个 API 地址。
* 导入备份时会做校验：格式不对会拒绝导入并保持原数据不变；
  如果导入的是很老的备份（没有强化题库），你现有的题库不会被清空。


四、第一轮：录入背诵 + 艾宾浩斯复习
----------------------------------------
【录入背诵】
  填科目、章节、标题、问题、答案、重要程度、学习日期，保存后自动排好复习计划。
  默认间隔是学习后第 1、2、4、7、15、30 天（可在"设置/备份"里改）。
  批量录入：展开"快速批量录入"，一行一条，格式是
      科目 | 问题 | 答案
  例：教育学 | 教育的本质是什么？ | 教育是有目的地培养人的社会活动

【今日复习】
  打开网页就算好了今天该复习哪些，顶部一直显示"今日待复习 N 条"。
  每条点开"看答案"，然后诚实地选一个：
      记得 → 进入下一个阶段，下次间隔更长
      模糊 → 阶段不变，明天再来一次
      忘记 → 重置到第一阶段，明天重来
  所有阶段走完就标为"已掌握"，60 天后再巩固一次（天数可改）。
  没有到期的内容时会提示"今天没有到期复习，可以自由安排"。
  逾期不会给你红色警告，只会温和标个"昨天 / 逾期 N 天"。

【抽背】
  可以从"今日待复习"里抽，也可以从"全部条目"里抽，还能指定科目。
  先只显示问题，想好了再点"显示答案"，然后自评。

【全部条目】
  搜索、按科目筛选，看每条复习过几次、历史自评记录，也能编辑和删除。


五、第二轮：强化阶段（按模块录入 + 随机抽题）
----------------------------------------
这一轮不按章节，而是按【模块】整理，五个模块：
      简答 / 名词解释 / 易混淆知识点 / 重难点 / 创新题

【怎么录】
  在「强化阶段」页面，选好模块 → 写题目 → 写答案/答题要点 → 保存。
  科目、小标题、重要程度、标签都可选；同一个模块可以录很多条。
  小技巧：题目框里按 Ctrl+Enter 可以直接保存。

【怎么抽题检验】
  在同一个页面的「按模块随机抽题」里选：
      抽哪个模块：某个模块，或者"全部模块（混合抽）"
      科目：只抽某个科目（可选）
      抽题范围：全部题目 / 还没检验过的 / 上次答得不好的（模糊 / 忘记）
  点"开始抽题"随机抽（可以抽一整轮），或者"只抽一条"。
  先只显示题目，想好了再点「显示答案」，然后诚实地选：
      记得 / 模糊 / 忘记
  每条都会记下检验次数和最近一次结果，列表里能看到历史。
  答得不好的那几条，下次把范围改成"上次答得不好的"再来一遍，很有效。

【题库】
  按模块分组显示，支持搜索题目/答案/标签、按模块筛选、编辑、删除，
  还能在列表里直接"抽这条"。

注意：第一轮（按章节，带艾宾浩斯复习）和第二轮（按模块，随机抽题）
是两个独立的题库，互不影响，各有各的用途。


六、备忘录（自己记的待办）
----------------------------------------
* 只写一行内容就能存；展开"更多选项"可以加：备注、日期（可选"无日期"）、
  时间、类型（待办/学习计划/生活杂事/随手记）、优先级、标签、重复。
* 重复支持：不重复 / 每天 / 每周 / 每月。完成后自动生成下一条
  （每天→明天，每周→7天后，每月→下个月同一天，如 1月31日 → 2月28日）。
* 首页顶部有"今日备忘"，显示"今天有 N 件小事记得处理"，逾期单独提醒。
* 想收系统通知：点"开启到期提醒"并允许通知权限即可。
  只在网页打开时检查一次，关掉网页不会后台推送；拒绝通知也不影响别的功能。


七、AI 陪伴怎么用
----------------------------------------
默认是【离线模式】：不联网，内置 70 多条温暖话术，按情绪匹配，够平时说说话。
快捷按钮：夸夸我 / 安慰我一下 / 今天学得好累 / 我有点焦虑 / 帮我复盘今天 / 给我一句鼓励。

想用真正的 AI 对话：
  设置/备份 → AI 陪伴设置 → 回复模式改成"在线 AI 模式"，然后填：
      API 地址：https://api.deepseek.com/v1      模型：deepseek-chat
      API 地址：https://api.openai.com/v1         模型：gpt-4o-mini
  需要有你自己申请的 API Key。没填对 / 网络不通 / 超时，
  会自动退回离线话术并温和提示一句，不会卡住。

  ！提醒：单文件网页没有后端，Key 是明文存在本机浏览器里的。
    建议用权限最小、额度最小的 Key，别在公用设备上填。
    导出的备份文件里不会包含 API Key。

  聊天记录最多保留最近 200 条，超出自动删最旧的；"清空聊天"会二次确认。


八、考试倒计时
----------------------------------------
页面最上方一直显示：距离 12月19日 还有多少天（还会显示约几周）。
考试当天会显示"今天就是 12月19日"，日期过了会显示已过去多少天。
想改成别的日期：设置/备份 → 考试倒计时 → 选日期 → 保存。


九、快速上手建议
----------------------------------------
想先看看长什么样：设置/备份 → 导入 JSON 恢复 → 选【示例数据.json】，
就会有一批示范内容。看完点"清空全部数据"即可从零开始。


十、其他细节
----------------------------------------
* 顶部显示当前时间、日期、考试倒计时，还有北京天气
  （来自 Open-Meteo 免费接口，无需密钥；拿不到时显示"暂时获取失败"，
   不影响其他任何功能）。
* 每天有一句"每日一句"和一件"拾取生活热爱的小事"，都按日期固定，第二天换新。
* 手机 / 平板上已做适配：输入框不会被自动放大、点击区域放大到手指好按、
  聊天区跟随屏幕高度、底部导航避开 iPhone 底部横条。
* 数据全在一个 key 里：beishu_app_v1


十一、出问题了怎么办
----------------------------------------
* 打不开 / 白屏：换 Chrome 或 Edge 试试（很老的 IE 不行）。
* 手机上打不开方式 C 的地址：
    ① 确认手机和电脑连的是同一个 Wi-Fi（不是手机流量）；
    ② 确认那个黑窗口还开着；
    ③ 电脑上弹出的防火墙提示要点"允许访问"。
* 数据不见了：是不是清了浏览器数据、换了浏览器或换了访问方式？
  如果之前导出过备份，用"导入 JSON 恢复"能找回来。
* 想从零开始：设置/备份 → 清空全部数据（会二次确认，建议先导出备份）。

祝复习顺利，慢慢来，比较快。
